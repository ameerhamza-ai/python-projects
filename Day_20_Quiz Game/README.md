# Python Quiz Game

> Day 20 of #150DaysOfAI — Week 3 Project

## About
A command-line Python quiz game with
10 carefully crafted questions covering
Weeks 1-3 concepts of #150DaysOfAI challenge.

## Features
- 10 Python questions (MCQ format)
- Live score tracking after each question
- 4 options per question (A/B/C/D)
- Input validation (.strip().upper())
- Grading system (A+ to C)
- Clean formatted UI

## Topics Covered
- Functions (def, return, kwargs)
- Data Types (list, tuple, dict, bool)
- Loops (for, while)
- Recursion (base case)
- Lambda & map()
- Scope & Variables

## Grading System
| Score | Grade | Remark |
|-------|-------|--------|
| 9-10 | A+ | Outstanding |
| 7-8 | A | Great Job |
| 5-6 | B | Good Effort |
| 0-4 | C | Need Practice |

## How to Run
```bash
python quiz_game.py
```
