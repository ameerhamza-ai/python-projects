# Pattern Generator

> Day 13 of #150DaysOfAI — Week 2 Project

## About
A menu-driven pattern generator
that prints 7 different shapes
with user-controlled size.

## Features
- 7 pattern types
- User controls size
- Menu-driven system
- Clean output

## Patterns Available
1. Right Triangle 
2. Inverted Triangle
3. Pyramid (Centered)
4. Diamond 
5. Number Triangle
6. Hollow Square
7. Alphabet Triangle

## Concepts Used
- Nested for loops
- while loop (menu system)
- Functions
- if/elif/else
- String multiplication

## How to Run
```bash
python pattern_generator.py
```
